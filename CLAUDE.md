# Preferencias del usuario

- **Estilo por defecto para todos los shorts nuevos:** el personaje de `stickman/motor.py` (clase
  `Personaje`), con el vestuario elegido según la historia o el audio que dé el usuario. Sigue la skill
  `.claude/skills/stickman/SKILL.md` (comando `/stickman`). Usa Blender (`realista/`) o Remotion (`/remotion`)
  solo si el usuario lo pide.
- Habla en español sencillo.
